# onisin OS — Documentation

Welcome. This is the documentation for onisin OS (OOS), an AI-first
platform for building data-driven enterprise applications without
writing application code.

## Where to start

If this is your first time here, read in order:

1. [Foreword](./foreword.md) — why OOS exists and which trade-offs it makes.
2. [What is OOS](./what-is-oos.md) — the one-page tour.
3. [How it works](./how-it-works.md) — the architecture and the data flow.

After that, jump to whichever section you need:

- [Writing contexts](./writing-contexts.md) — describe what your data looks like.
- [Designing screens](./designing-screens.md) — describe how it is rendered.
- [The AI assistant](./the-ai-assistant.md) — how the LLM fits in.
- [Security and roles](./security-and-roles.md) — who is allowed to do what.
- [Running OOS](./running-oos.md) — installation, seed, configuration.
- [The toolbox](./the-toolbox.md) — the tools that ship alongside OOS.
- [Glossary](./glossary.md) — CTX, DSL, context, entity, and friends.
- [License](./license.md) — the short version.

## About these docs

OOS is under active development. Some details will shift. When something
in the docs disagrees with the code, the code wins — and we want to know
so we can fix the docs. Open an issue or a merge request with the file
name and the paragraph that got out of step.
